# Documentación del repositorio

Este directorio contiene la documentación del proyecto kiromind-ai-codebase-expert.

Propósito
- Reunir guías, arquitectura, y material útil para contribuyentes y usuarios.

Estructura sugerida
- docs/README.md               (este archivo)
- docs/getting-started.md      Guía rápida para empezar
- docs/architecture.md         Diagrama y descripción de la arquitectura
- docs/contributing.md         Cómo contribuir
- docs/changes.md              Registro de cambios y notas de versiones

Cómo usar
- Lee `getting-started.md` para configurar el entorno de desarrollo.
- Sigue `contributing.md` si quieres enviar cambios.

Contacto
- Para dudas, abrir un issue en el repositorio.
